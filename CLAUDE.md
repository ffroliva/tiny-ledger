# CLAUDE.md

**Read [`AGENTS.md`](AGENTS.md) — it is the source of truth for working in this repository.**

This file exists only to route you there. It is intentionally not a second copy: this project is
agent-agnostic, and every tool's convention file (`CLAUDE.md`, `.cursorrules`, `GEMINI.md`,
`.github/copilot-instructions.md`) points at the same document so that Claude, Codex, Cursor, Aider,
Gemini, Hermes or a human all start from identical rules. Two sources of truth would mean one is wrong
and nobody knows which.

For finding documentation on need rather than reading it all, use [`docs/INDEX.md`](docs/INDEX.md).

Do not add rules here. Add them to `AGENTS.md`.
